---
description: Check if a newer HOTL version is available
---

Run the HOTL update check script to see if a newer version is available:

```bash
bash scripts/check-update.sh
```

If an update is available, it will show the installed version, latest version, and the command to run. If you're already on the latest version, the output will be silent.

To update: run the update command shown in the output.
